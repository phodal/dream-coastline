# 中后段戏剧场景补强

这份 pass 用来修正第四到第七幕容易读成任务卡的问题。原则是：每个文明建设节点都必须让一个角色承担代价、反驳或遗留，而不是只展示系统进度。

## 第四幕：续文院不是建筑完成

### 第一批成员

闻素带来的不是“教师资源”，而是一群愿意承认自己还不会的人。阿棠带来的不是“工坊产能”，而是旧制度里每次先发现故障、却没有解释权的人。夏离带来的旧军地图，也不再服务王令，而要接受公共章程复核。

这一场的戏剧功能是让续文院从“建设据点”变成一次权力重排：谁有资格读字，谁有资格指出错误，谁有资格叫停一项危险工程。

### 第一堂课与错误记录

小砚问自己写歪的名字会不会被收回。闻素的回答不是鼓励，而是规则：写歪的字不能擦掉，要留下改正路径。这里回收第一幕“名字会被删除”的恐惧，把它改写成“名字可以被学习共同体保护”。

### 阿棠的工坊复盘

防洪符文事故不能只作为 build workflow 前置条件。阿棠必须指出旧制度会把事故记在一个工匠头上，而续文院要把它记在流程上。纪子轩的行动不是“修好机器”，而是让故障拥有公开解释权。

## 第五幕：百年不是蒙太奇

### 闻素的空椅

闻素不该只以教材名出现。她留下的空椅要让纪子轩听见一条延迟回答：不要让我的名字替你们上课。学生没有停课，才证明她真的教会了他们。

### 阿棠最后一张蓝图

阿棠的 payoff 不是成为伟大工程师，而是留下一张会被后人继续批改的故障预判。蓝图页边出现新笔迹：“已漏，已改，已公开。”这让她从功能角色变成工程传统的开端。

### 小砚的点名声

小砚晚年的点名录是第一幕无名危机的长线回收。点名不是课堂管理，而是确认每个普通人的名字仍被系统等待。这条遗留物要在终章现代学校再次被调用。

## 第六幕：归星不是热血表决

### 归星议会

支持派不能只说报恩，反对派也不能只阻挠。闻素反对把归星简化成报恩，因为报恩轻到可以由一个人决定；反对派摊出能源、学塾、备份清单，让玩家承认“害怕再次失去”是正当政治立场。

风险账本是这一幕的戏剧中心。它把“是否救另一个世界”改成“失败时谁先断电、谁先撤离、谁有权叫停”。这能让归星计划成为文明成熟度测试，而不是主角个人愿望。

### 空座名单

续页舰的空座不是煽情，而是冗余设计。阿棠要说明：工程不是出发，而是你失败以后，别人还能接着修。这一场把归星计划从英雄远征拉回可追责的公共工程。

### 归星门告别

告别场必须让闻素、阿棠、小砚都留下具体可用的东西：闻素留下公开复核，阿棠留下过热拆解规则，小砚留下呼名原则。终章不是“大家一起加油”，而是纪子轩带着他们的方法回到现代。

## 第七幕：最终协议要举证

静默协议不能只重复“该文明应静默”。它要先举证：现代文明能把信号送向深空，却无法保护每个名字；能制造高速系统，却把错误藏进黑箱；能照亮城市，却让孤立的人在灯下消失。

玩家反证也不能是口号。反证链应调用前六幕成果：

- 闻素的教材证明错误能公开学习。
- 阿棠的桥栓证明工程能被后来者接手。
- 小砚的点名证明普通人的名字值得等待。
- 夏离和国书备份证明权力可以拆成责任。

最终 Continue 的含义因此变成：现代文明尚未合格，但它已被两个世界共同纳入可修正的下一页。

## 父母线后日谈

结局不需要立刻团圆。静默协议被拒绝后，父母只留下两枚可追踪坐标和半句“下一页见”。这比直接重逢更符合当前主题：主线完成的不是找回父母，而是把寻找父母的路修到能被记录、复核和继续。
